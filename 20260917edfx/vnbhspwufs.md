# 不孕症患者能用避孕药么？

> 更新时间：2026-09-17 (UTC+8)

在不孕症的患者中，相信很多人（尤其是PCOS、排卵障碍者）对诸如妈富隆、达英等短效避孕药都不陌生。同时大家也会有很多疑问。

1.我是来看不孕症的，而医生给我用避孕药，靠谱么？
这时候医生开的避孕药是用来改善患者体内紊乱的内分泌环境，从而达到调整月经周期的目的。所以不必紧张，可以用。

2. 短效口服避孕药是“激素”，是不是也会像其他激素一样出现副作用？
不会的。这是因为此激素非彼激素，激素“好”与“不好”，还要看功能和剂量。糖皮质激素，由肾上腺分泌，也可以通过化学的方法人工合成。这种由人工合成的糖皮质激素有一定的抗炎作用，在临床被用于比较严重的感染（败血症等），也可用于治疗一些风湿免疫病。大剂量应用时会引起消化道溃疡、肥胖等副作用，严重的还会引起骨头坏死。

 
短效口服避孕药中的激素则不同，尽管其中雌激素和孕激素是人工合成的，但是结构和作用与人体自身分泌的激素非常接近，并且在发挥药效的过程中，模拟的是人体自然状态。更重要的是，目前短效口服避孕药中的雌激素含量一般只有20-35 
ug，这种程度的剂量是很安全的，因此不会导致像糖皮质激素那样的副作用。 

3. 停止服用后的次月就怀了孕，孩子会不会不健康呢？
大量研究证明，停止服用短效口服避孕药后即可妊娠，不会对未来的胎儿和生育功能有影响。另有研究表明，不仅停药后妊娠不会对胎儿造成影响，即使已经怀孕了而在无意中服用了，也不会增加致畸的风险。

4. 服用期间如果有1天忘了吃，怎么办？
建议大家服药时一定要按照医嘱来用，通常调经时，是从自然月经来潮的第5天开始吃起，连吃21天后停药7天，大部分人停药后在第3到4天就会有月经（撤退性出血）。另外要注意的是，最好在每天的同一时间服用，而且不要漏服。由于短效口服避孕药剂量低、代谢快，一旦漏服，可能会对内分泌造成影响，甚至有些人会出现阴道少量不规则出血。因此，如果漏服是在12h之内应立即补服一片，超过12h后则根据说明书采取相应的补救措施。 

另外提醒大家，服用短效避孕药调经前一定要测尿妊娠试验，排除早孕后再用。
